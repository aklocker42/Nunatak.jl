Model overview ​

Nunatak evolves the thickness of an ice sheet or ice shelf on a two-dimensional Oceananigans grid whose vertical direction is Flat. Column quantities such as the viscosity, the velocity profile and the enthalpy live on a terrain-following σ grid built from the same horizontal grid (see Numerics).

Building a model ​

julia
using Oceananigans, Oceananigans.Units, Nunatak

year = years = 31556926seconds

grid = RectilinearGrid(CPU(); size = (64, 32), halo = (4, 4), x = (0, 640kilometers), y = (0, 80kilometers),
                       topology = (Bounded, Bounded, Flat))

model = IceSheetModel(grid;
                      rheology = GlenFlowLaw(grid; rate_factor = 6.3e-25),
                      friction = WeertmanFriction(grid; coefficient = 3e6),
                      stress_balance = DepthIntegrated(shear = DIVAShear()),
                      grounding = SubgridGroundedFraction(),
                      bed = (x, y) -> -150 - 1e-3 * x,
                      surface_mass_balance = 0.3 / year)

set!(model, H = (x, y) -> ifelse(x < 600kilometers, 500.0, 0.0))
simulation = Simulation(model; Δt = 1year, stop_time = 10years)
run!(simulation)

All parameters that can be fields, such as the bed, the friction coefficient, the rate factor and the mass balance, are stored as Fields so that gradients with respect to them exist (see Gradients). Units are SI throughout: metres, seconds, pascals; rates are per second. Oceananigans.Units has no year, so the examples define year = years = 31556926seconds, the year of the MISMIP+ and EISMINT specifications.

One time step ​

IceSheetModel works with Oceananigans' Simulation, run!, output writers, Checkpointer and TimeStepWizard. Each step, time_step!(model, Δt) advances the thickness with a split Runge–Kutta scheme (three stages by default). After the final stage a PartialCellFront advances the calving front. update_state! then

  1. diagnoses the geometry from the new thickness,

  2. solves the stress balance for the velocities, when the velocity solver's schedule actuates,

  3. advances the enthalpy by one implicit column step, when thermodynamics are present.

The velocities used during a step are therefore those of the geometry at the start of the step.
